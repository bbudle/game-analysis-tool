# 게임 분석 도구

게임별 핵심 재미와 콘텐츠 순환, 콘텐츠 관계, 시스템 구현 설계를 탐색하는 정적 웹사이트입니다.

## 수정 및 배포

- `data.json`: 게임 분석 데이터. 시스템 테이블은 원본 추출물이 아닌 구현 제안입니다.
- `app.js`: 화면과 상호작용
- `style.css`: 디자인
- `page.html`: HTML 템플릿
- `python build.py`: 루트의 `index.html` 재생성

수정 후 `python build.py`를 실행하고 변경 파일과 index.html을 함께 커밋합니다.
GitHub Pages는 main 브랜치의 루트를 배포합니다.

## 저장 범위

개인 메모와 사용자가 추가한 게임은 브라우저 저장소에만 저장됩니다. 서버 계정이나 공동 편집 기능은 없습니다.
미확인 정보는 확인 필요로 구분합니다. 비공식 분석 자료이며 게임 권리자와 무관합니다.
